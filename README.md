# MonChien パラパラ工房

犬の動きを並べたシートをコマごとに切り出し、位置をそろえて重ね、LINEのアニメーションスタンプ・アニメーション絵文字用のAPNGとZIPを書き出すツールです。

- ブラウザだけで動きます(インストール不要、外部ライブラリなし)
- 画像はすべてブラウザの中で処理し、どこにも送信しません

## 使い方
1. 犬の動きのシート画像を追加 → 自動で切り出し・位置合わせ
2. 文字の画像を重ねて、動きを選ぶ
3. 「セットに入れて、次の1個へ」で24個ためる
4. スタンプ用・絵文字用のZIPを書き出す

規定はLINE Creators Marketの制作ガイドラインをもとにしています。申請前に最新の規定を確認してください。
